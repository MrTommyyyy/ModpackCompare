# Contributing

Report a reproducible problem with the command used, Python version, expected
result and actual result. Remove personal folder paths before posting reports.
Discuss larger features in an issue before starting a pull request.

Run `python -m unittest discover -v` before submitting changes. Add a regression
test when fixing a behaviour that could break again. Keep runtime dependencies
in the Python standard library and explain changes to output formats.

This project is an initial release. Contributions and feedback are welcome.
